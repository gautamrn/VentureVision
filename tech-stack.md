# Venture-Vision Stack (2026)

## Backend (Agent Core)
- **Language:** Python 3.12+
- **Framework:** FastAPI (Asynchronous endpoints)
- **Orchestration:** LangGraph (Stateful Agent Workflows)
- **Model:** Claude 3.5 Sonnet
- **Search:** Tavily AI (Search API for LLMs)
- **Validation:** Pydantic v2
- **Logging:** LangSmith (Logic Observability)

## Frontend (Dashboard)
- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Strict Utility, No Gradients/Effects)
- **UI Components:** Shadcn UI (Standard variants: Outline/Ghost/Default)
- **Streaming:** Server-Sent Events (SSE) for agent status updates.
